# MOP Critique

Public macOS downloads and the signed automatic update feed for MOP Critique. Application source is maintained separately.

[Download the latest release](https://github.com/max-uho/mop-critique-releases/releases/latest). Requires macOS 12 or later; universal for Apple Silicon and Intel. Open the signed, notarized DMG and copy MOP Critique to Applications. Existing app identity and user data are preserved.

Reading, searching, filtering and opening highlights in Apple Books are free. Pro unlocks annotation-note editing, highlight-color changes, deletion, and book title/author editing. Activate a signed Pro license in Settings (Command-comma). Apple Books access is controlled by macOS Full Disk Access.

Version 0.1.12 introduces automatic updates. Install it once manually if you use 0.1.11 or earlier. Thereafter use MOP Critique > Check for Updates (Command-Shift-U), or the automatic startup/daily check, then Install and Restart.

Report bugs in this repository's issues with app/macOS versions and reproduction steps. Do not upload private Books databases, annotations or license tokens. Test editing with backed-up data.
